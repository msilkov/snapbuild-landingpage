# snapbuild-landingpage

Воспроизведение лендинга снэпбилд с дополнительными секциями.

Опубликовано: https://msilkov.github.io/snapbuild-landingpage/

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка продакшен-версии: `npm run build`, предпросмотр: `npm run preview`.

## Стек

React 19, TypeScript, Vite, Tailwind CSS v4.

## Решения по реализации

Почему код написан именно так — система размеров, приёмы вёрстки, разбор секций
и грабли Tailwind v4: [docs/decisions.md](docs/decisions.md).

Подробное описание работы появится по мере готовности секций.
